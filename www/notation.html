personal notation

This is an alternate notation that I made that translates into the ischool relational notation standard.

notation rules

  • the minimum table is "table_name(primary_key)" because all tables need at least one primary key
  • define columns by using snake_case (case insensitive) words separated by either a comma, a semicolon, or a newline
  • non pk columns are included in the optional {} block after the primary keys
  • foreign keys are made by adding "=table.pk" after any key. the referenced column needs to be a valid pk on another table
  • whitespace doesn't matter at all so you can go wild
